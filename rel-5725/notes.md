## v5.7.25

### Nexora Jam invites, fully Nexora-branded
- Jam invite links now open **our own invite page** (https://mdsarimsd-ui.github.io/nexora-jam/) instead of upstream LastWave's page: Nexora branding, the room code shown on the page, "Open in Nexora" (deep link) and "Get Nexora free" pointing to our GitHub releases.
- Old LastWave invite links still open Nexora normally.
- Jam workflow is unchanged: host creates a room, shares the code or link, everyone joins and stays in sync. Rooms still run on the same free sync server.

### Optional capped ads scaffold (off by default)
- Support for showing a maximum of 3 ads per day with a 90-minute gap, disabled out of the box and only active once configured with AdMob app/ad IDs.
